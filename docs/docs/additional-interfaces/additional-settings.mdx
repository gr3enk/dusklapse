## JPG Transfer

This option lets you specify how many JPG frames should be transferred to Dusklapse via Wi-Fi to conserve battery life. It’s important to note that Dusklapse can only control the timelapse correctly if enough JPGs are transferred.

## Twilight Calculation

This option allows you to specify how Dusklapse's Auto Luminance feature calculates twilight. The following options are available:

| Option       | Sun below horizon |
| ------------ | ----------------- |
| Civil        | -6°               |
| Nautical     | -12°              |
| Astronomical | -18°              |
