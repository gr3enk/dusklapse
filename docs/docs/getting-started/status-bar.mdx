The following page describes all the elements of the status bar. It refers to the numbers in the diagram below.

![interface](/img/interface/status_bar.webp)

## Parameters

Under items 1–3, you can view the current camera settings (shutter speed, ISO, and aperture) and change them using the drop-down menu.

The small dot next to each setting label indicates whether ramping is enabled for that setting. This indicator is ...

- gray when ramping is disabled for that parameter.
- white when ramping is enabled for that parameter.
- blue when that parameter is currently being ramped.

## Exposure Meter

The exposure meter (4) displays the exposure relative to the set luminance reference value.

## Additional Options

The following additional settings can be found under points 5-9:

- The name of the connected camera (5)
- Settings menu with additional options (6)
- Timelapse Interval Calculator (7)
- [Log view](/docs/additional-interfaces/logs), where communication with the camera is logged (8)
- Disconnect the current connection (9)

## Status Informations

- Elapsed time since the first frame (10)
- Number of frames captured (11)
- Estimated duration of the time-lapse sequence (12)
- Camera battery level (13)
